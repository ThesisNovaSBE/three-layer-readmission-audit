## Key decisions made

**Correct evaluation population for Stage 1+2:**
- Stage 2 can only act on patients with discharge notes
- In real clinical use, every discharged patient has a note — the 37% gap is a MIMIC-IV-Note coverage limitation
- All Stage 1+2 metrics are now reported relative to the notes cohort (43,776 patients, 11,186 positives)
- This changes recall from 12.2% (wrong denominator) to meaningful values

**Operating threshold: thr₂ = 0.3**
- +21% precision over Stage 1 alone (0.256 → 0.309)
- Retains 70.9% of true positives within the notes cohort
- F2 = 0.563 (vs 0.632 Stage 1 baseline on notes cohort)
- stage2_results.csv updated accordingly

**Stage 2 training setup is correct (no change needed):**
- Training on all patients with notes (not just Stage 1-flagged) is intentional — avoids training on a biased high-risk subset
- Per-patient pipeline is the right real-world design: Stage 1 → Stage 2 → Stage 3 triggered per patient

**Stage 3 design:**
- No training, pure inference via Ollama (phi4-mini)
- `--limit N` added so thesis demo doesn't run on all 25k patients
- Real deployment: each confirmed patient triggers Stage 3 individually
