## Key decisions made

- **Part 0 (colleague patch):** `add_special_tokens=False` in
  `call_llm_batch` (the chat template already adds them); mid-rank tie
  guard in `discordance._percentile_rank` (kept even after Part 1, for
  Stage 2 ties); `--resume` header-guard in `run_batch_audit` (SystemExit
  if an existing output file's header doesn't match the current schema).
- **Part 1 (raw-score rank):** the isotonic-calibrated Stage 1 score has
  only ~47 distinct values above the flag threshold, so r1 percentile
  ranks were tied/biased. `predict.py` now stores `stage1_score_raw`
  (uncalibrated XGBoost prob) in both results CSVs; `pipeline._cohort_scores`
  / `_lookup_patient` / `compute_discordance` rank r1 on the raw score
  (r2 unchanged, calibrated). Missing column raises (no silent fallback).
  The prompt still shows the CALIBRATED score as the probability.
- **Part 2 (head+tail note cap):** notes over 20,000 chars were cut at the
  end, dropping discharge/disposition/follow-up. New `src/stage3/_notecap.py`
  shows head 12k + marker + tail 8k (newline-trimmed), via ONE helper
  (`_shown_note_text`) used for both the prompt and quote verification --
  a quote matching only the omitted middle now counts as unverified.
- **Part 3:** D2 `_get_patient_feature_row` raises `KeyError` instead of
  fabricating an all-zero row; D3 `_detect_truncated` takes the full stop-id
  set (EOS + `<end_of_turn>` + `generation_config.eos_token_id`); D5 SHAP
  lines say `SHAP=+0.180 log-odds` and the prompt header names the unit;
  D1 prep-failure rows get `discordance_mode="PREP_FAILED"` / `displacement=NaN`
  and are excluded from the sweep and the discordance subgroup analysis.
  Did NOT move the attention Longformer to GPU (D4, memory risk).
- **Part 4:** C1 `_control_arm_report` selects the top
  `m = round(rate * n)` by RAW score (stable argsort), so the realised
  alert count matches the pipeline's to within one admission; old
  calibrated-threshold arm kept as a labelled secondary field. C2
  `run_validation_controls` reports D1/D2 agreement primarily vs the
  batched reference arm (D3 run 1, same batch composition), vs main run
  secondary.
- **Part 5:** smoke-run checklist added to `slurm_stage3_batch.sh`.
