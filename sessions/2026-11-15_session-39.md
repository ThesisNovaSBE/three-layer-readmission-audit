  (failed+annotation_failed)/processed > 0.2, print the first three errors,

  `slurm_stage3_batch.sh` exits at start if that marker exists.
- **N7 (timing/memory):** per-chunk average SHAP / attention / generation time
  via a module-level `_PREP_TIMINGS` accumulator (avoids adding a param that
  would breach max-args) + `torch.cuda.max_memory_allocated()`. No device change.

- **N9 (acceptance gate):** `acceptance_check_stage2.py` is now BLOCKING
