## What triggered this session

The age fairness analysis (`analyse_age_fairness.py`) revealed two critical problems in the old Stage 2:

1. **Age bias persisted**: Stage 1 had a 6.8 pp precision gap across age groups; Stage 2 barely narrowed it to 6.2 pp
2. **Stage 2 introduced a recall gap**: 70+ recall=0.620 vs 0.751 for younger groups — 13 pp disparity Stage 2 itself created
3. **Root causes**: 512-token limit missed frailty/social context in elderly notes; 15k notes with label-only stratification left only ~820 elderly readmission notes in training; no validation/calibration split; no fairness-aware loss

Decision: full Stage 2 rebuild from scratch with proper methodology.

## Architecture changes

### Data splits (new — was missing entirely)
- Patient-level split (subject_id) to prevent leakage
- 60% fine-tune / 20% validation / 20% calibration — all from Stage 1 training patients
- Stage 1 test set (20% of all patients) locked and used only for final evaluation
- Splits saved as CSVs for reproducibility

### Training data (improved)
- Age×label stratified sampling: 8 cells (4 age bands × 2 labels)
- 70+ oversampled: target 4,500 readmit + 8,000 non-readmit notes
- Total ~45k training notes (up from 15k), all unique (no duplication)

### Sequence length: 512 → 2048 tokens
- Average MIMIC discharge note: ~1,900 tokens
- 512 captured ~27% of the average note (missed frailty, functional status, social sections)
- 2048 captures ~100% of the average note — requires GPU

### Loss function: weighted CE → Focal Loss + age group weights
- Focal loss (γ=2.0): downweights easy examples, upweights hard ones
- Age group loss weights: 70+=1.3×, 56–70=1.1×, younger=1.0×
- Both mechanisms together address the elderly underperformance

### Calibration (new — was missing)
- Platt scaling per age group on calibration set
- Threshold selection: recall_floor≥0.65 per group, then F2-optimal within that constraint
- Calibrated thresholds saved to models/stage2_calibration.json
- Test set used exactly once for final reporting
