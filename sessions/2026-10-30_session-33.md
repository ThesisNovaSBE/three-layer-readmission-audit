## Task #6 — the four remaining decisions, resolved this session

Walked the user through all four with context; they decided, with
rationale, on all four — written into `docs/ARCHITECTURE.md` §5 as
"Resolved 2026-10-30":

- **RQ1 headline denominator**: notes-covered subset (AUROC 0.7093 vs.
  0.7101) is the headline; full-population number (0.7215) is context
  only. Confirms what `README.md`/`MODEL_CARD.md` already presented —
  this formalizes it as decided, not provisional.
- **Identical Stage 1/2 splits**: no — current design (same test
  partition, Stage 2's training further restricted to notes-covered
  admissions within Stage 1's training side) is correct, not an open
  question. Restricting Stage 1's training data to notes-only would have
  thrown away real training data for no benefit; the actual requirement
  (same test admissions for both) is already met.
- **Stage 3's evidence bundle** (raw features vs. SHAP strings): leave
  as-is. Found a strong, project-grounded reason rather than "didn't get
  to it": giving Stage 3 raw structured features risks drifting back
  toward the exact design session 11 already rejected — an LLM narrating
  a structured model's own SHAP values, "a well-trodden pattern with no
  novel finding." Worth having this answer ready for the defense.
- **Per-age-band context for Stage 3**: no, deliberately not pursued —
  Stage 1 and Stage 2 already carry their own targeted bias-mitigation
  machinery; adding explicit age context to Stage 3 too risks compounding
  corrections or introducing a new inconsistent-treatment vector rather
  than reducing bias. Verified and disclosed one honest nuance: `age` can
  still appear *incidentally* via a patient's top-5 SHAP block if it's a
  top risk driver for that admission — not the same thing as the
  systematic framing this question was actually about.

All four already match the actual code/doc presentation as it stands —
nothing needed to change in `MODEL_CARD.md`/`README.md`'s numbers, only
`ARCHITECTURE.md` §5's status needed to move from "open question" to
"confirmed, with rationale."
