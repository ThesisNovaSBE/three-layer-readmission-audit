## Key decisions made

- **Conditional Stage 3 triggering: resolved, not adopted as the execution
  mode.** `run_batch_audit` still audits every Stage 1-flagged, note-covered
  admission (unchanged). Discordant-only triggering is answered instead as
  a post-hoc analysis over a completed blanket run
  (`_conditional_triggering_report`) — committing to conditional as the
  design would mean never learning what auditing concordant cases finds,
  and no full batch run has happened even once yet, so there's no cost
  currently being saved by skipping it. The cost/benefit trade-off (LLM
  calls saved vs. metric delta) is now a measured, reportable result
  instead of a design assumption.
- **Operating point K: stays at 0.15 (primary).** A colleague's proposal to
  make K=20% primary had no comparable justification to the existing
  clinical-capacity argument behind 0.15 (session 15). Not changed without
  new operational evidence. 20%/10%/5% remain secondary
  `capacity_report_points`, unchanged.
- **Grounds taxonomy replaces the single `primary_clinical_domain`.** Ten
  fixed grounds (4 mitigating, 6 aggravating), each requiring its own
  verbatim quote, independently verified. Fixed list only — an invalid
  ground or empty quote fails the whole response, same enforcement level
  the old domain/decision/quote fields already had.
- **Two decisions, not one: `decision_model` (the LLM's own free judgment)
  and `decision_rule` (the same three-way decision recomputed
  deterministically in code from the extracted grounds).** This resolves
  the tension ARCHITECTURE.md §5 item 3a had left unresolved (small
  additions to the schema vs. replacing the free decision with pure
  extraction) — `decision_rule` gives a deterministic, human-checkable
  fallback without ever replacing `decision_model` as the value that drives
  the pipeline's final prediction.
- **`insufficient_evidence` added as a third decision value**, computed
  code-side from note length (`_MIN_INFORMATIVE_NOTE_CHARS`) for
  `decision_rule`, and as a real option the LLM itself can pick for
  `decision_model`. `evaluate_pipeline.py:_apply_stage3_decisions` updated
  to treat it as "no usable coverage" (falls back to the prior C9-corrected
  prediction), not silently miscounted as either uphold or override.
- **Prompt field order fixed independently of the rest of the migration.**
  The prior prompt asked for `decision` before the supporting quote/
  justification — a real autoregressive-conditioning bug (the colleague's
  critique was correct, verified against the actual template, not just
  plausible). Grounds/evidence are now requested before decision.
- **Schema-constrained Ollama generation** (`format=<JSON schema>`) replaces
  the generic `format="json"` — the installed `ollama` client (0.6.1)
  supports this; not yet measured whether it reduces the parse-failure rate
  since no real batch run has happened yet.
- **`supporting_quote`/`quote_verified` dropped**, superseded by per-ground
  quotes + an aggregate `all_quotes_verified`. `planned_return` stays a
  separate, always-answered field — deliberately not merged into the
  grounds list, even though "planned_return" also exists as a mitigating
  ground the model may cite when it drives the decision.
- **Two validation controls added as diagnostic functions, not wired into
  the default batch path:** blind-note control (rerun with the note
  withheld — tests whether the auditor is actually reading it) and
  no-Stage-2 control (rerun with Stage 2's score/discordance withheld —
  tests whether Stage 2 earns its place in the prompt). Both implemented by
  adding `suppress_note`/`suppress_stage2` parameters to `explain_patient`
  and a `hide_stage2` parameter to `build_prompt`, not a separate duplicated
  code path.
- **Self-agreement check added** (temperature=0 has never been empirically
  verified to actually produce identical output across two calls) — a
  standalone diagnostic to run once before a full Phase C5 batch run.
- **A real gap found, not fixed this session:** no included-vs-excluded
  (notes-covered vs. not) selection-bias comparison table exists anywhere
  in the repo. Recorded in ARCHITECTURE.md §4 as deferred, not built.
