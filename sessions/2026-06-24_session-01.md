## What I worked on

Initial repository skeleton for the readmission prediction pipeline.

## Key decisions made

- Two-stage pipeline architecture: high-recall classical ML (Stage 1) → Bio_ClinicalBERT false-positive pruning (Stage 2), with optional Ollama explanation (Stage 3).
- Real MIMIC-IV data is NEVER committed. All data paths are configured via `.env` / `config.yaml`, gitignored.
- Dual-mode data: if real MIMIC paths exist locally, use them; otherwise fall back to synthetic data with identical column schemas. This lets anyone develop and test without credentialed access.
- Config precedence: `.env` overrides `config.yaml` values.
- Column schemas defined in `src/schemas.py` as the contract between data stages.
