## Key decisions made

- The control arm is the single most load-bearing ablation arm and did not
  need a separate N1 runner script — implemented inline in
  `evaluate_pipeline.py` as `_control_arm_report`, reusing
  `select_threshold_for_capacity` and the existing `_pipeline_report` shape.
- `verify_quote` is a plain verbatim substring check, not a semantic
  entailment check. Deliberately cheap: it catches fabricated quotes, which
  is the failure mode that matters for human review, not misleading-but-real
  quotes.
- All 5 of Stage 3's required JSON fields (decision, domain, quote,
  quote-non-empty, planned_return) are enforced at the same level in
  `_parse_response` — a missing quote or missing planned_return fails
  parsing exactly like a missing decision does. No silent partial-success
  state.
- Did **not** implement conditional Stage 3 triggering (auditing only
  discordant cases), even though I had flagged it in the prior session as
  "the next BUILD NOW item" — the user explicitly said they want to evaluate
  that question themselves before deciding. Recorded it as open in
  `docs/ARCHITECTURE.md` §5 instead of building it.
- `docs/THESIS_NARRATIVE.md`'s abstract numbers (AUROC 0.706, recall 0.85,
  "+21% precision") were replaced with an explicit retrain-pending
  placeholder rather than deleted or left as-is — they're stale-model
  artifacts (the old recall-floor Stage 1 and pre-fairness-rebuild Stage 2),
  not current results, and leaving them in would risk them being copy-pasted
  into the actual thesis as if current.
