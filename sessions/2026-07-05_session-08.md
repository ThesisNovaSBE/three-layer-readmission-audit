## Frontend built (`frontend/`)

**Stack:** React 18 + TypeScript + Vite + Tailwind CSS (same as colleague's ATML_Sepsis_Alert project)

**Two views:**

1. **Pipeline tab** (main view for professor meeting):
   - Visual Stage 1 → Stage 2 → Stage 3 diagram with real metrics per stage
   - "How it works" section with plain-language explanation of each stage
   - 4 key metric cards (AUROC, Recall, Precision gain, F2)
   - Designed to explain the full pipeline logic to a non-technical audience

2. **Patients tab** (clinical dashboard):
   - Sortable table of confirmed high-risk patients (by Stage 1 score, Stage 2 score, age)
   - Risk badges (color-coded by severity), score bars, readmission ground truth
   - Click any row → modal with full patient profile + Stage 3 narrative explanation
   - 8 synthetic representative patients with realistic clinical explanations

## Key design decisions

- **Synthetic patients only in frontend** — stage2_results.csv is gitignored (MIMIC data policy); mock data reflects real pipeline statistics (precision=0.309, readmission rate=25.6%)
- **Pipeline tab first** — professor meeting is the immediate use case
- **No backend** — pure static frontend; real data could be loaded via CSV import or a thin Flask API later
